## 🚀 Project Overview

**Sales Performance Analyzer** is an interactive Excel data-analysis project that transforms raw sales data into meaningful business insights.

This project combines **Excel formulas, PivotTables, Conditional Formatting, What-If Analysis, Data Analysis ToolPak, Linear Regression, Descriptive Statistics, and an interactive dashboard**.

---

## 🎯 Project Objectives

- Analyze customer purchasing behavior
- Identify high-value customers
- Compare regional and product performance
- Track monthly sales trends
- Analyze the relationship between Sales and Profit
- Perform descriptive statistical analysis
- Perform Linear Regression using the Data Analysis ToolPak
- Analyze discount/profit scenarios using What-If Analysis
- Build an interactive PivotTable dashboard
- Present insights through professional visualizations

---

## 🛠️ Excel Features Used

| Feature | Purpose |
|---|---|
| Conditional Formatting | Highlight top customers based on total purchase |
| What-If Analysis | Analyze discount/profit scenarios |
| Linear Regression | Analyze Sales vs Profit |
| Descriptive Statistics | Summarize important dataset statistics |
| PivotTables | Analyze sales by region, product, and month |
| Slicers | Filter by Region and Product Category |
| Timeline | Filter by Order Date |
| INDEX + MATCH | Identify high-value customers |
| FILTER | Return matching customer records |
| SUMIF / SUMIFS | Calculate customer and monthly metrics |
| NOW() | Create timestamp values |
| Icon Sets | Display monthly sales growth direction |
| Charts | Visualize trends, comparisons, and relationships |

# 🎛️ Dashboard Interactivity

### Region Filter

The **REGION** slicer filters results by:

`Central | East | North | South | West`

### Product Filter

The **PRODUCT_CATEGORY** slicer filters results by:

`Books | Clothing | Electronics | Furniture | Office Supplies`

### Date Filter

The **ORDER_DATE** Timeline filters dashboard results by month.

Connected KPI cards and PivotCharts update according to the selected filters.
